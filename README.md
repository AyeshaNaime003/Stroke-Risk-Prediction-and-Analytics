# Stroke-Risk-Prediction-and-Analytics

Part 1 — Data science notebook

EDA, data quality checks, class imbalance analysis, SMOTE applied only to training data, baseline comparisons, hyperparameter tuning, evaluation and final model selection.


Part 2 — Reusable ML pipeline

A Scikit-learn Pipeline with preprocessing and model steps, saved as one artifact. This helps ensure the same transformations are applied during training and prediction.


Part 3 — Django web application

User input, validation, prediction results, prediction history and database storage. Keep the model logic separate from the Django views.


Part 4 — Interactive analytics dashboard

Dataset-level trends, class distributions, model comparisons and evaluation metrics. Distinguish historical dataset analysis from individual predictions.


Part 5 — Software quality

Automated tests, clear project structure, Docker, environment configuration and a reproducible setup guide.
